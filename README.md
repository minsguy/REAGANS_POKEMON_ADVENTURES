# Reagan's Pokémon Adventures

A camera-based Pokémon hunting game for the iPad. Open the site in Safari, tap Start, allow the
camera and motion sensors, then turn around to find Pokémon in your room and flick the Pokéball
to catch them. Caught Pokémon are saved to the Pokédex on the device.

Live: https://minsguy.github.io/REAGANS_POKEMON_ADVENTURES/

Personal, non-commercial family project. Pokémon artwork is loaded from the PokéAPI sprite
repository and belongs to Nintendo / Game Freak / The Pokémon Company.
